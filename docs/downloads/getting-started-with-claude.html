Getting started guide

Working with Claude:
Cowork & Claude Code

How to get real work done with Claude — spreadsheets, documents, research, and everything in between. Which tool to open, how to ask, and what to do when something breaks.

The short version

Open Cowork for almost everything. It reads and writes files in folders you choose, connects to Google Drive and Gmail, and shows you every step it takes before anything is final.

Claude Code is the power tool. It runs in a terminal, and it's what Giles uses to build things. You don't need it day to day — think of it as the workshop out the back that Giles sets up when a job calls for it.

The two tools

Both are Claude underneath — same intelligence, different workbench.

Claude Cowork
Your daily driver

An assistant that works in your files

  • Reads, edits and creates files in folders you designate — Word, Excel, PDF, text
  • Connects to Google Drive, Gmail and Sheets
  • Shows every step and file it touches, so you can review before trusting
  • Keeps working on long tasks even after you close the laptop
  • No terminal, no setup beyond pointing it at a folder
Claude Code
The power tool

An agent that builds and automates

  • Runs in a terminal — built for developers
  • Deeper automation: custom skills, scheduled jobs, repeatable workflows
  • More capability, but fewer guardrails — a wrong approval can overwrite files
  • Needs someone comfortable fixing it when it misbehaves
  • This is Giles' territory — ask him before going here

Honest rule of thumb: if the job is done once and reviewed by you, it's Cowork. If the job should keep happening on its own, it's Claude Code — and that's a "talk to Giles" moment, not a solo mission.

How Claude reaches your files

Three connections matter, and they're set up once:

1. Folders on your computer. You choose which folders Cowork can see. It can read, edit and create files there — nothing outside them. Keep one working folder (say, Documents/Claude) and drop files in when you want Claude on them.

2. Google Drive connector. Lets Claude read your Docs and Sheets, and save new files to Drive. One catch: it can't edit an existing Google Sheet or Doc — reading only.

3. The Google workspace connection (Giles sets this up). This is the piece that lets Claude actually update existing Sheets and Docs, and prepare Gmail drafts. It runs through your machine, so:

Keep the Claude desktop app open when you're working with Google Sheets or Docs. The Google connection runs locally — if the app is closed, Claude can read Drive but can't make edits.

Common scenarios

The situations you'll actually hit, which tool to open, and how to ask. Being specific about the outcome you want is 80% of getting a good result.

Update a spreadsheet with new numbers

Cowork

Claude reads the sheet, makes the changes, and shows you what it did. Always name the exact file and tab.

Try saying"Open the sheet called 2026 Budget, go to the July tab, and add these figures: … Then tell me which cells you changed."

Turn messy notes into a polished document

Cowork

Drop the notes (or a voice-memo transcript) into your Claude folder and describe the audience and format you want.

Try saying"Take meeting-notes.txt from my Claude folder and turn it into a one-page summary for the team — plain language, decisions first, action items at the end."

Make sense of a pile of documents

Cowork

Point Claude at a folder and ask for exactly the comparison or extraction you need. It will work through every file and cite which one each finding came from.

Try saying"Read every PDF in the Invoices folder, pull out the supplier, date and amount from each, and build me a spreadsheet with one row per invoice."

Draft emails you'd actually send

Cowork

With the Gmail connection, Claude can read a thread and prepare a draft — it lands in your Drafts folder, and nothing sends without you.

Try saying"Find the latest email thread with the school about the excursion, and draft a short, friendly reply confirming attendance. Save it as a draft for me to check."

Research something properly

Cowork

Claude can search, read, compare and write up findings in one go. Say what decision the research is for — you'll get answers instead of a book report.

Try saying"Compare the three CRM options in shortlist.xlsx for a small business: monthly effort to run, what each is best at, and which you'd pick for someone non-technical. One page."

A report you need every single week

Starts in Cowork → Claude Code

Do it in Cowork the first few times until the format is right. Once it's routine, that's the signal to automate — Giles can set up Claude Code to produce it on schedule, and you just review the result.

Try saying(to Giles) "I've done this same Monday report in Cowork three weeks running — same steps every time. Can we automate it?"

Four habits that make Claude much better

These come straight from how Giles works with Claude every day. They work in Cowork, Claude Code, and plain chat.

1. Ask for evidence, not reassurance

Claude sometimes says "done" optimistically. Make it prove the work before you trust it.

Try saying"Before you tell me it's finished, show me the exact cells you changed and their new values."

2. Start sessions with a catch-up

Each new conversation starts fresh. Rather than re-explaining, ask Claude to rebuild context from your files first.

Try saying"Catch me up: read the project folder and tell me in three bullets where things stand before we continue."

3. Ask for a picture

When an explanation gets long, a diagram is faster. Claude can draw the process instead of describing it.

Try saying"That's a lot of words — show me this as a simple diagram instead."

4. De-AI the writing

First drafts from any AI share the same tells — too enthusiastic, too many lists, words nobody uses. Ask for a pass in your own voice.

Try saying"Rewrite that the way I'd actually say it — shorter sentences, no buzzwords, warm but direct."

When something breaks

"I can't access your Google account" / Sheets edits stop working
The Google connection has dropped — it happens periodically and it's a two-minute fix. Message Giles.
"You've reached your usage limit"
Cowork uses your allowance faster than normal chat. It resets after a few hours — not broken, just resting. Save long jobs for one focused session rather than lots of small ones.
Claude edited the wrong thing
Don't panic — Cowork lists every file it touched. Check the step log, and ask Claude to reverse the change. Version history in Google Docs/Sheets has your back too.
The result is generic or misses the point
Usually a prompt problem, not a Claude problem. Add the three things it can't guess: the audience, the format you want, and what "good" looks like.
