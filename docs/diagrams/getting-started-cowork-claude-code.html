Getting Started: Cowork & Claude Code
A non-technical onboarding guide. Cowork is the daily driver for documents, spreadsheets and research; Claude Code is the power tool for building and automation. When to open which, how to ask, and what to do when something breaks.
The short version
🟢
Open Cowork for almost everything
It reads and writes files in folders you choose, connects to Google Drive and Gmail, shows every step it takes, and keeps working on long tasks after you close the laptop. No terminal, no setup beyond pointing it at a folder.
🔨
Claude Code is the power tool
Terminal-based, built for developers. Deeper automation — custom skills, scheduled jobs, repeatable workflows — but fewer guardrails. It's the workshop out the back: brilliant when a job calls for it, not where a non-technical user starts.
Which one, when
📊
Done once, reviewed by you → Cowork
Summarising documents, updating spreadsheets, drafting reports and emails, researching a decision, working through a folder of PDFs. If a human checks the result, Cowork is the right bench.
⚙️
Keeps happening on its own → Claude Code
Weekly reports on a schedule, small tools and trackers, anything that should run without you. That's a "talk to whoever runs your setup" moment, not a solo mission.
How Claude reaches your files
1
Folders on your computer
You choose which folders Cowork can see; it can read, edit and create files there and nowhere else. Keep one working folder and drop files in when you want Claude on them.
2
Google Drive connector
Lets Claude read Docs and Sheets and save new files to Drive. The catch: it cannot edit an existing Google Sheet or Doc — reading only.
3
The Google workspace connection
A local MCP server that unlocks editing existing Sheets and Docs and preparing Gmail drafts. It runs through your machine, so keep the desktop app open when working with Google files — and note it only works in local sessions, not remote or scheduled ones.
Common scenarios
📈
Update a spreadsheet — Cowork
Name the exact file and tab: "Open the 2026 Budget sheet, go to the July tab, add these figures, then tell me which cells you changed."
📝
Messy notes into a polished doc — Cowork
Drop the notes in your Claude folder and name the audience and format: "Turn meeting-notes.txt into a one-page summary for the team — decisions first, action items last."
📂
Make sense of a pile of documents — Cowork
"Read every PDF in the Invoices folder, pull out supplier, date and amount, and build a spreadsheet with one row per invoice." Claude cites which file each finding came from.
✉️
Draft emails — Cowork
With the Gmail connection, Claude reads a thread and prepares a reply that lands in your Drafts folder. Nothing sends without you.
🔍
Research a decision — Cowork
Say what the research is for, not just the topic: "Compare the three options in shortlist.xlsx for a small business and tell me which you'd pick for someone non-technical. One page."
🔄
A report you need every week — both
Do it in Cowork until the format is right. Once it's the same steps three weeks running, that's the signal to automate it in Claude Code — and just review the result.
Four habits that make Claude much better
✅
Ask for evidence, not reassurance
"Before you tell me it's finished, show me the exact cells you changed and their new values." The same habit behind the verification-before-completion skill.
🔄
Start sessions with a catch-up
Each conversation starts fresh. "Read the project folder and tell me in three bullets where things stand before we continue." See the resume skill.
🗺️
Ask for a picture
When an explanation gets long: "Show me this as a simple diagram instead." The visualise skill exists because this works.
✍️
De-AI the writing
First drafts share the same tells — too enthusiastic, too many lists. "Rewrite that the way I'd actually say it — shorter sentences, no buzzwords." See the humanizer skill.
When something breaks
🔌
"I can't access your Google account"
The workspace connection has dropped — it happens periodically and re-authenticating takes two minutes. Message whoever set up your connection.
⏳
"You've reached your usage limit"
Cowork uses your allowance faster than normal chat. It resets after a few hours — not broken, just resting. Prefer one focused session over many small ones.
↩️
Claude edited the wrong thing
Cowork lists every file it touched. Check the step log, ask Claude to reverse the change, and remember Google's version history has your back.
🎯
The result is generic
Usually a prompt problem. Add the three things Claude can't guess: the audience, the format you want, and what "good" looks like.
Level 2 — making Claude yours
🎯
The Starter Kit
Once the basics above feel comfortable, the next step is teaching Claude your standards and your job: ten paste-in ground rules (no invented facts, evidence before "done", drafts stay drafts), a who-I-am brief template, and three copy-paste routines for operations-style work — stress-test a plan, triage a recommendation list, prove-it's-done checking. All copy-paste, no technical setup: downloads/claude-starter-kit.html.
