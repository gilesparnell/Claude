Getting to Know Claude
The reading order for going from "never used Claude" to a trained, trustworthy daily assistant — no developer tools required. Docs are written for a non-technical reader and added to this index as the series grows. Read them in order; each builds on the last.
The series so far
# Doc What it's for Why
01 Getting Started with Claude The basics: the two tools (Cowork for everyday work, Claude Code for automation), which to open when, how Claude reaches your files, common scenarios with sample prompts, and what to do when something breaks. The first hour. Without this, Claude is a chat box; with it, it's an assistant working in your actual files. Read before anything else.
02 Making Claude Yours — the Starter Kit Personalisation in three copy-paste layers: ten ground rules (no invented facts, evidence before "done", drafts stay drafts), a who-I-am brief template, and three repeatable routines — grill my plan, triage recommendations, prove it's done. Out of the box, Claude doesn't know you or your standards. Twenty minutes of setup turns confidently-plausible into actually-reliable — the difference that makes it safe for real work.

Both docs also exist as fully self-contained single HTML files that render on a phone — the basics and the starter kit — sendable over WhatsApp or email as-is.

Coming next

The series grows one doc at a time. Queued: working with spreadsheets properly, building your first weekly-report Project, and getting good answers from documents. Each new doc gets a row in the table above — this page is the only index you need to bookmark.

How to use this series
📖
Read in order
The docs build on each other — doc 02 assumes the habits from doc 01. Every doc carries a series breadcrumb at the top so you can step backwards and forwards without coming back here.
⏰
One doc, then practice
Don't binge the series. Read one doc, use Claude on real work for a few days, then come back for the next — the habits stick far better that way.
